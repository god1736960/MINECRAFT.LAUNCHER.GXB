# MINECRAFT.LAUNCHER.GXB 🎮
Un lanzador personalizado de Minecraft con soporte para Java Edition, Bedrock Edition, Minecraft Dungeons y Minecraft Legends.

## ✨ Características
- ✅ Interfaz limpia inspirada en el lanzador oficial
- ✅ Sistema de skins y capas con vista previa en 3D
- ✅ Soporte para Java, Bedrock, Dungeons y Legends
- ✅ Novedades dinámicas con tarjetas rotativas
- ✅ Búsqueda y filtros integrados
- ✅ Funciona en modo local sin necesidad de cuenta premium

## 📂 Cómo usarlo
Abre el archivo `index.html` en tu navegador. Las versiones de Minecraft se descargan desde los servidores oficiales de Mojang.

## ⚠️ Notas importantes
- Este es un proyecto de creación personal y de aprendizaje
- No es un producto oficial de Mojang Studios
- Las imágenes y recursos pertenecen a sus respectivos propietarios
